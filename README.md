# 🌾 AgriMap – Smart Agriculture Management System

AgriMap is a full-stack web application designed to support smart agriculture by managing crop data, farmer information, weather monitoring, and data analysis.  
It provides role-based access where **Admin** can manage data and **Users** can view insights.

---

## 🚀 Features

### 🔐 Authentication
- Admin login
- User login
- Role-based access control

### 📊 Dashboard
- Overview of agriculture modules
- Clean and responsive UI

### 🌱 Crop Management
- View crop details
- Admin can add and delete crops
- Crop attributes:
  - Season
  - Soil type
  - Water requirement
  - Region

### 👨‍🌾 Farmer Management
- View farmer information
- Admin can add farmer details
- Displays land and crop information

### ☁️ Weather Monitoring
- Live weather data
- Live 7-day weather forecast
- Uses OpenWeatherMap API

### 📈 Data Analysis
- Crop distribution by season
- Water requirement distribution
- Region-wise crop distribution
- Dynamic calculations from real data

---

### Frontend

### Backend
- Node.js

### APIs
